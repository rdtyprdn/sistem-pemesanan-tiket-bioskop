# sistem-pemesanan-tiket-bioskop
Tujuan dari pembuatan Sistem Pemesanan Tiket Bioskop adalah untuk membantu proses pengelolaan dan pemesanan tiket secara digital. Dengan adanya sistem ini, diharapkan dapat mempermudah admin dalam mengelola data bioskop serta membantu customer dalam melakukan pemesanan tiket, mulai dari melihat film hingga memilih kursi dan menyelesaikan pemesanan.
